# Vocaby on Android

Vocaby is a language tool that empowers users in the digital space. 

## Minimum Marketable Features
- Users can search for definitions
- Users can save definitions
  - Users can log in to sync with their Google Extension Account.
- Users can place a widget in the home screen to review saved definitions
  - The widget will refresh periodically, changing the word to review.
- Users can create a widget for _Words of the Day (WoD)_.
