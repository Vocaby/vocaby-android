# Vocaby on Android
Vocaby provides tools that empower individuals learning the English language.

## Minimum Marketable Features
1. Users can look up a word in the Vocaby dictionary.
    - A word _could_ have a pronunciation.
    - A word **must** have a definition.
    - A definition _could_ have a sentence.
    - A definition **must** have a part of speech associated with it.
    - The looked up words are saved as search histories.
        - This could be cleared. 
    - Users could look up a word offline.
    - Users could look up a word using the Vocaby API for broader word coverage.
2. Users can save words.
    - Users can select multiple words to delete.
    - Users can delete all words in one go.
3. Users can register/login/logout.
    - User data will be synced across platforms when logged in.
    - Users can delete their account.
4. Users can create a widget in the home screen to review saved definitions.
    - The widget will refresh periodically, changing the word to review.
    - Users can refresh the widget manually.
5. Users can turn on notifications to be notified of their saved words for review.
    - Users can change the refresh frequency.  
6. Users can view _Word of the Day (WoD)_ in the main screen.
