# Vocaby on Android
Vocaby provides tools that empower individuals learning the English language.

## Minimum Marketable Features (v1.0.0)
1. Users can look up a word in the Vocaby dictionary.
    - A word could have a pronunciation.
    - A word must have a definition.
    - A definition could have a sentence.
    - A definition must have a part of speech/type associated with it.
2. The looked up words are saved as search histories.
    - This could be cleared.
3. Users could look up a word offline.
4. Users could look up a word using the Vocaby API.
    - Vocaby Dictionary will be maintained to provide broader word coverage and up-to-date definitions. 
5. Users can save words (Offline/Online).
6. Users can view their saved words.
    - Saved words are paginated (15 items per page).
    - Users can delete a saved word.
7. Users can edit definitions for existing words, or create a new entry in the dictionary.
8. Users can register/login/logout.
    - Users can reset their password.
9. User data will be synced across platforms when logged in.
10. Users can delete their account.
11. Users can create a widget in the home screen to review saved definitions.
    - The widget will refresh periodically, changing the word to review.
    - The user can refresh the widget manually.
    - The widget will always prefer user-defined definitions over Vocaby definitions.
12. Users can turn on notifications to be notified of their saved words for review.
    - The notification will always prefer user-defined definitions Vocaby definitions.
    - Users can change the notification refresh frequency.
13. Users can view Word of the Day (WoD) on the main screen.
